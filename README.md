# Private Credit Deal Screener

Grades a private credit deal on coverage, leverage and collateral, shows which assumptions move the score most and drafts a short investment committee memo.

Live: https://alenzacodes.github.io/private-credit-screener/

## How to use

Open the live page, or clone the repo and open index.html in a browser. No build step and no install. Change the inputs and the results update as you go.

Run the tests with Node:

    node tests/test.js
